# Module 10: Opening Night

## The question this module answers

Handed a genuinely new job end to end, can I do it all, and leave with something I'll actually use
again?

## Where it sits in the arc

Tenth module, the synthesis capstone. Prerequisite: all of Modules 01 through 09. No next module.
See [`modules/README.md`](../README.md) for the full arc.

## Learning objectives (placeholder - finalized when content is authored)

- Complete an end-to-end assignment spanning every capability the workshop taught, against new
  facts the learner hasn't seen before.
- Assemble a complete, personal, reusable pack from everything kept across the prior nine modules.
- Re-engage the real-folder safety ritual from Module 09, even though this module's own artifacts
  stay inside the sandbox.

## Exercise material to draw from (not a spec - authored during the content-building pass)

The season opener: Tilghman assigns the full package - a research brief, an event document, a
cleaned spreadsheet, a renamed photo set, and confirmation letters - against a capstone-only fixture
packet with new figures not derivable from any prior module's fixtures. See
`docs/workshop-design.md` §7, Module 10 row, for the anti-resubmission design this binds to.

## Required gate (placeholder - shape decided now, real checker written later)

- **Required checklist (primary):** a cross-artifact checker drawing one mechanism from each of
  Modules 04, 06, 07, and 08, every one bound to the new capstone packet's own data, plus a
  Module-05-style structural check on the research brief, plus a pack-completeness check (the
  personal `CLAUDE.md`, at least six prompt recipes, the cheatsheet, the mini-script recipes from
  Module 08, and the safety-ritual checklist from Module 09 are all present).
- **Short write-up (secondary):** does the assembled package read as something the learner will
  actually use next month, and does the work show genuine re-engagement with this module's own new
  facts rather than resubmitted prior work - named honestly as a gap no automated check can fully
  close, per `docs/workshop-design.md` §7's own discussion of this limit.

## Takeaway

The full assembled pack: personal `CLAUDE.md`, prompt library, mini-script recipes, and safety
ritual - the literal artifact of "fluent."

## Stop condition (placeholder)

The checker script passes with the full count, and the write-up shows genuine engagement with the
capstone's own new facts.
