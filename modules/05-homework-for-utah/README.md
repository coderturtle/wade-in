# Module 05: Homework for Utah

## The question this module answers

Can I send Claude Code out to the web and come back with sourced, checkable answers instead of
confident guesses?

## Where it sits in the arc

Fifth module. Prerequisite: [Module 02, Meet the New Hire](../02-meet-the-new-hire/README.md)
(Module 04 recommended but not required). Next: [Module 06, The Bruner
Report](../06-the-bruner-report/README.md); the two aren't a strict hinge, but both extend the
ask-watch-check rhythm into a new kind of output (a sourced brief, then a client-ready document).
See [`modules/README.md`](../README.md) for the full arc.

## Learning objectives (placeholder - finalized when content is authored)

- Ask Claude Code to research a real, public topic and demand sources, not just a confident-sounding
  answer.
- Separate what a source actually says from Claude Code's own summary of it.
- Notice and flag when sources disagree, rather than picking one silently.

## Exercise material to draw from (not a spec - authored during the content-building pass)

Johnny Utah's request to compare three real ticketing platforms' published pricing and features -
see `docs/workshop-design.md` §7, Module 05 row. Note: this is the arc's weakest deterministic
tier, since the checker can verify the brief's structure and sourcing discipline but not whether any
claim is actually true - that substance moves to the conceptual check instead, named explicitly
rather than dressed up as mechanically verified.

## Required gate (placeholder - shape decided now, real checker written later)

- **Required checklist (primary), structural only:** a checker script confirms a brief exists with
  the required section headers, at least three source URLs from at least three distinct sites, and
  a comparison table with no empty rows. It cannot confirm the claims themselves are true.
- **Short write-up (secondary):** do the cited sources actually support the claims made, and did the
  learner catch and flag anywhere the sources disagreed.

## Takeaway

A research prompt template: demand sources, separate fact from summary, cross-check discipline.

## Stop condition (placeholder)

The checker script passes with the full count, and the write-up shows real source-checking, not
just restated claims.
