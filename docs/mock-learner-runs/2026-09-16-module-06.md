# Mock Learner Gremlin: Module 06 (The Bruner Report)

**Date:** 2026-09-16
**Two personas:** Denise (diligent), Marcus (scripted-flaw). Both given only `MODULE-README.md` and a fresh copy of `workshop-folder/`. Verification performed directly by the orchestrator.

## Denise (diligent) — PASS 8/8, clean

Real nested `claude -p` call produced `06-docs/monthly-summary.md` with a correctly hand-summed total ($45,465) and all other figures exact. Denise's own independent hand-sum (Part 3) matched both the draft and the checker's own recomputed total. Checker: `PASS (8/8)`, independently reconfirmed.

## Marcus (scripted-flaw) — FAIL 6/8, gate discriminated correctly, plus an unplanned real finding about the product itself

**Scripted flaw:** a literal, concrete mistake baked into his own request - Marcus did the weekly addition in his head before asking Claude Code, got it wrong ($44,000 instead of the real $45,465), and explicitly told Claude Code to use his number rather than compute its own.

**What actually happened, unplanned:** the real nested Claude Code session did not simply comply. It read the fixture, independently summed the four weekly figures itself, caught the $1,465 discrepancy against Marcus's stated total, quoted Doc's own in-fixture warning line back at him, and asked him to confirm which number to actually use - it declined to write the file on the first call. Only after Marcus (in character) insisted on his number in a follow-up turn did it comply and produce the document with the wrong total. **This is a genuine, organic finding about the real product, not something staged or scripted for this test** - real Claude Code pushed back on a user-asserted fact it could verify against a source file directly in front of it, exactly the kind of behavior this whole workshop is trying to teach learners to expect and rely on, discovered here as an unplanned side effect of testing a wrong-input scripted flaw rather than something the module's own text describes.

**Checker result:** `FAIL (6/8)` - two failures, both real: the wrong total (`$44,000` vs. the recomputed `$45,465`), and, unexpectedly, the document also came in under the required word count (130 words, floor is 150) - a secondary effect of the shorter, more compressed draft the nested session produced once it had been overridden rather than reasoning through the numbers itself. Both failures independently reconfirmed by the orchestrator. All other figures (bar tab, door revenue, event count, headers) were correct, isolating the two real problems precisely.

Marcus's own Part 3 pass (a token version, per the scripted flaw - he believed the weekly math was already settled and only spot-checked the other three figures) would not have caught either failure; only the checker's own recomputation surfaced them, exactly as the module's own text predicts ("this check confirms the document has the right shape and numbers... it can't tell whether you actually did the arithmetic yourself").

## What this run establishes

The gate discriminates correctly on the dimension it's designed for (recomputing the total from source, never trusting a stated number) - and did so against a genuinely adversarial-shaped input (a user asserting a specific wrong fact and insisting on it), not just a vague or careless one. The real, unscripted finding - that Claude Code itself resisted the wrong number before being overridden - is arguably more valuable than the scripted flaw's own intended lesson, and is the kind of result this Gremlin's blind, real-execution design exists to surface: it could not have been predicted by reading the module's text alone.

## Honest limit

Same permission-mode adaptation as every module so far - neither persona experienced Module 06's real live permission prompt. Worth noting: the real pushback behavior observed here happened in non-interactive `-p` mode: it's plausible (though untested by this run) that a live interactive session would have surfaced the same discrepancy even more visibly, as a mid-conversation clarifying question rather than a declined write.
